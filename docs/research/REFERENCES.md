exact claim each source supports are in `RELATED_WORK.md`. Sources were checked on 2026-10-21
(L1–L19) and 2026-10-27 (L20–L30). None is future-dated. Where only metadata or a secondary
description was read, `RELATED_WORK.md` says so, and the document relies on that source only for
what its abstract or official page states.
